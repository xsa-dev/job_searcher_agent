# Проверка авторизации на HeadHunter

**Версия**: 2.0.1  
**Дата**: 2025-11-07

---

## 🎯 Назначение

Функция `_check_if_logged_in()` автоматически определяет, авторизован ли пользователь на сайте HeadHunter, анализируя содержимое страницы.

---

## 🔍 Алгоритм проверки

### 1. Получение snapshot страницы

```python
snapshot_tool = tools_by_name["browser_snapshot"]
snapshot_result = await snapshot_tool.ainvoke({})
page_content = str(snapshot_result).lower()
```

### 2. Поиск индикаторов авторизации

**Проверяемые элементы меню HH:**

| Элемент | Тип | Описание |
|---------|-----|----------|
| "резюме" | Пункт меню | Ссылка на резюме пользователя |
| "профиль" | Пункт меню | Ссылка на профиль |
| "отклики" | Пункт меню | История откликов |
| "сообщения" | Иконка | Иконка сообщений в хедере |
| "уведомления" | Иконка | Иконка уведомлений в хедере |
| "notifications" | Иконка | Англ. версия уведомлений |
| "messages" | Иконка | Англ. версия сообщений |
| "responses" | Пункт меню | Англ. версия откликов |

### 3. Поиск индикаторов НЕавторизации

**Проверяемые элементы:**
- "войти"
- "вход"
- "sign in"
- "log in"

### 4. Принятие решения

**Правило 1**: Если найдено **2+ элемента** авторизации И **0 элементов** неавторизации
```
→ Пользователь АВТОРИЗОВАН ✅
```

**Правило 2**: Если найдено **3+ элемента** авторизации (независимо от кнопки "Войти")
```
→ Пользователь АВТОРИЗОВАН ✅
```

**Иначе**:
```
→ Пользователь НЕ АВТОРИЗОВАН ❌
```

## 🔧 Интеграция в Browser Agent

### Автоматическая проверка

```python
# В browser_agent_node
if state["browser_session_active"] and state["browser_status"] != "logged_in":
    logger.info("🔍 Проверка статуса авторизации...")
    is_logged_in = await _check_if_logged_in(tools_by_name)
    
    if is_logged_in:
        logger.info("✅ Пользователь уже авторизован!")
        state["browser_status"] = "logged_in"
        # Пропускаем логин, переходим к следующему шагу
    else:
        logger.info("❌ Пользователь не авторизован, требуется логин")
        # Выполняем логин
```

### Экономия времени

| Сценарий | Без проверки | С проверкой |
|----------|-------------|-------------|
| Первый запуск (не авторизован) | Логин 10-20 сек | Проверка 1-2 сек + Логин 10-20 сек |
| Повторный запуск (авторизован) | Логин 10-20 сек | Проверка 1-2 сек ✅ |

**Экономия**: ~10-18 секунд при повторных запусках

## 🔒 Обработка ошибок

### Try-Catch блок

```python
try:
    # Проверка авторизации
    ...
except Exception as e:
    logger.error(f"❌ Ошибка проверки авторизации: {e}")
    return False  # По умолчанию считаем не авторизованным
```

### Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `browser_snapshot` не найден | Инструмент не загружен | Проверить загрузку MCP tools |
| Timeout при snapshot | Страница не загрузилась | Увеличить timeout |
| Пустой snapshot | Браузер не запущен | Запустить браузер |

## 🚀 Использование

### В составе graph_agent

Проверка выполняется автоматически при каждом запуске Browser Agent:

```bash
uv run python main.py
```

**Что происходит:**
1. Browser Agent запускается
2. Автоматически проверяется авторизация
3. Если авторизован → пропуск логина
4. Если не авторизован → выполнение логина

### Принудительная проверка

Можно вызвать вручную:

```python
is_logged_in = await _check_if_logged_in(tools_by_name)
if is_logged_in:
    print("Пользователь авторизован")
else:
    print("Требуется логин")
```
