# Логика пропуска уже откликнутых вакансий

**Версия**: 2.0.2  
**Дата**: 2025-11-08

---

## 🎯 Назначение

Browser Agent автоматически определяет вакансии, на которые уже был отправлен отклик, и пропускает их без генерации письма и траты времени.

---

## 🔍 Как это работает

### 1. Проверка при открытии вакансии

```
Открытие вакансии → Новая вкладка → Проверка кнопки "Откликнуться"
                                           ↓
                                    Есть кнопка? 
                                    ↙          ↘
                                  ДА           НЕТ
                                  ↓             ↓
                          Продолжить      Пропустить
                          отклик          вакансию
```

### 2. Признаки уже откликнутой вакансии

**Проверяется наличие:**
- ❌ Отсутствие кнопки "Откликнуться"
- ✅ Наличие текста "Отклик отправлен"
- ✅ Наличие текста "Already applied"
- ✅ Наличие статуса отклика

### 3. Действия при обнаружении

```python
if "already_applied" in response:
    # 1. Логирование
    logger.warning("⚠️ На вакансию уже был отправлен отклик")
    logger.info("➡️ Пропускаем эту вакансию")
    
    # 2. Добавление в список
    state["already_applied_urls"].append(vacancy_url)
    
    # 3. Переход к следующей вакансии
    state["current_vacancy_index"] += 1
    state["current_vacancy"] = None
    state["cover_letter"] = ""
    
    # 4. НЕ увеличиваем счетчик откликов
    # state["applied_count"] остается без изменений
```

## 🖥️ Работа с вкладками

### Проблема

HeadHunter открывает вакансии в новых вкладках при клике. Нужно правильно управлять вкладками.

### Решение

**Добавлен инструмент `browser_tabs`:**

```python
browser_tabs(action, index)
```

**Доступные действия:**
- `action="list"` - получить список вкладок
- `action="new"` - создать новую вкладку
- `action="select", index=N` - переключиться на вкладку N
- `action="close", index=N` - закрыть вкладку N

### Типичный workflow

```
1. Клик на вакансию → Открывается вкладка #1
2. browser_tabs(action="select", index=1) → Переключение на вакансию
3. Проверка кнопки "Откликнуться"
4. Если есть → отправка отклика
5. browser_tabs(action="close") → Закрытие вкладки с вакансией
6. browser_tabs(action="select", index=0) → Возврат на главную вкладку
```

### В промпте

```
ВАЖНО О ВКЛАДКАХ:
- При клике на вакансию она открывается в НОВОЙ вкладке
- После клика используй browser_tabs(action="select", index=1) для переключения
- После отклика закрой вкладку: browser_tabs(action="close")
- Вернись на главную вкладку: browser_tabs(action="select", index=0)
```

## 📈 Преимущества

### 1. Экономия времени
- Не тратится время на генерацию письма (~10-15 сек)
- Не тратится время на попытку отклика (~5-10 сек)
- **Итого:** ~15-25 секунд на каждую уже откликнутую вакансию

### 2. Экономия токенов
- Не вызывается Cover Letter Agent (~800-1200 токенов)
- Не генерируется письмо

### 3. Избежание ошибок
- Нет попыток повторного отклика
- Нет ошибок от HH API
- Чистая статистика откликов

### 4. Правильный учет
- Счетчик `applied_count` отражает реальные отклики
- Список `already_applied_urls` пополняется
- История корректна

## 🔧 Интеграция

### В browser_agent_node

```python
# Обработка статуса already_applied
elif "already_applied" in last_response.lower():
    logger.warning(f"⚠️ На вакансию '{state['current_vacancy'].get('title')}' уже был отправлен отклик")
    logger.info("➡️ Пропускаем эту вакансию и переходим к следующей")
    
    # Добавляем URL в список
    vacancy_url = state['current_vacancy'].get('url', '')
    if vacancy_url and vacancy_url not in state["already_applied_urls"]:
        state["already_applied_urls"].append(vacancy_url)
    
    # Переходим к следующей вакансии БЕЗ увеличения счетчика
    state["current_vacancy_index"] += 1
    state["current_vacancy"] = None
    state["cover_letter"] = ""
    state["browser_status"] = "idle"
```

## 🧪 Тестирование

### Ручной тест

1. Найти вакансию на которую уже был отклик
2. Запустить систему с этой вакансией
3. Проверить логи:
   - ⚠️ Должно быть предупреждение
   - ➡️ Должен быть переход к следующей
   - ❌ Счетчик откликов не должен увеличиться

### Ожидаемое поведение

| Состояние вакансии | Действие | applied_count | current_vacancy_index |
|-------------------|----------|---------------|----------------------|
| Кнопка "Откликнуться" есть | Отправить отклик | +1 | +1 |
| Кнопка отсутствует | Пропустить | 0 | +1 |
| "Отклик отправлен" | Пропустить | 0 | +1 |

## 🚀 Использование

### Автоматическое

Логика работает автоматически при каждом отклике:

```bash
uv run python main.py
```

**Что происходит:**
1. Browser Agent открывает вакансию
2. Проверяет наличие кнопки "Откликнуться"
3. Если есть → отправляет отклик
4. Если нет → пропускает вакансию

### Статистика

В конце сессии можно увидеть:
```
📊 Статистика:
  - Всего вакансий: 10
  - Откликов отправлено: 5
  - Пропущено (уже откликнуто): 3
```
