# Исправление подключения к Chroma MCP Server

## Проблема

При запуске `uv run python main.py` возникала ошибка:
```
error: Failed to spawn: `chroma-mcp-server`
  Caused by: No such file or directory (os error 2)
```

**Причина:** Система пыталась запустить `chroma-mcp-server` через stdio, но команда не была доступна. При этом Chroma уже был запущен отдельно через `make chroma-start` на SSE (Server-Sent Events) транспорте.

## Решение

### 1. Изменен транспорт для Chroma
**Файл:** `main.py`

- **Было:** stdio транспорт с попыткой запуска команды
- **Стало:** SSE транспорт с подключением к уже запущенному серверу

```python
"chroma": {
    "url": "http://localhost:8091/sse",
    "transport": "sse",
}
```

### 2. Chroma сделан опциональным
**Файл:** `main.py`

- Добавлена проверка доступности Chroma сервера перед подключением
- Если сервер недоступен, система продолжает работу без Chroma
- Playwright остается обязательным компонентом

### 3. Улучшено управление сессиями
**Файл:** `main.py`

- Использован `AsyncExitStack` для корректного управления несколькими сессиями
- Playwright и Chroma сессии управляются независимо

## Использование

### Вариант 1: С Chroma (рекомендуется)

1. Запустите Chroma сервер:
   ```bash
   make chroma-start
   ```

2. Запустите систему:
   ```bash
   uv run python main.py
   ```

Система автоматически обнаружит Chroma и подключится к нему.

### Вариант 2: Без Chroma

Просто запустите систему:
```bash
uv run python main.py
```

Система автоматически определит что Chroma недоступен и продолжит работу без него.
