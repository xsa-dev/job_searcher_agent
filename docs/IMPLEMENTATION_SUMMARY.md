## 🏗️ Архитектура

### До (Simple Agent)

```
User → Agent → LLM → MCP Tools → Browser
         ↓
    Single Flow
```

### После (Multi-Agent System)

```
                    ┌─────────────┐
                    │ Supervisor  │ ◄── Router
                    └─────┬───────┘
                          │
            ┌─────────────┼─────────────┐
            │             │             │
            ▼             ▼             ▼
      ┌─────────┐   ┌──────────┐  ┌─────────┐
      │ Planner │   │ Browser  │  │ Letter  │
      └─────────┘   │  Agent   │  │  Agent  │
            │       └──────────┘  └─────────┘
            │             │             │
            └─────────────┴─────────────┘
                          │
                    ┌─────▼──────┐
                    │   State    │
                    │  (History) │
                    └────────────┘
```

### Workflow цикла

```
START → Supervisor → Planner (план)
                ↓
        Supervisor → Browser (логин)
                ↓
        Supervisor → Browser (поиск)
                ↓
        ┌───────────────────────┐
        │  FOR каждой вакансии: │
        │                       │
        │  Supervisor → Letter  │
        │  Supervisor → Browser │
        │  Supervisor → check   │
        └───────────────────────┘
                ↓
            END (лимит/цель)
```

## 🔑 Ключевые особенности

### 1. Адаптивное планирование

Planner Agent:
- Анализирует последние 10 сессий из истории
- Выявляет успешные паттерны (высокие scores)
- Корректирует план на основе результатов
- Учитывает уже обработанные вакансии

### 2. Персистентность данных

SessionStorage:
- JSON файлы в `data/sessions/`
- Структурированное хранение вакансий
- Статистика по каждой сессии
- Агрегированная история

### 3. Избегание дубликатов

Система проверяет:
- URL вакансий в последних 50 сессиях
- Автоматически пропускает уже обработанные
- Сохраняет в `already_applied_urls` set

### 4. Генерация писем

Cover Letter Agent:
- Использует Foundation Model (MiniMaxAI)
- Персонализирует под вакансию
- Учитывает успешные примеры из истории
- Формат: 500-1000 символов
