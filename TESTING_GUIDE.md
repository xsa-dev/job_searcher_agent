### 5. Что делать при проблемах

#### Проблема: "Последовательность неполная"
```
❌ Последовательность неполная: respond=True, type=False, submit=False
```
**Причина:** Агент не заполнил письмо или не нажал "Отправить"  
**Решение:** Проверьте логи итераций Browser Agent, возможно нужно увеличить `max_iterations`

#### Проблема: "Не удалось подтвердить отправку отклика"
```
⚠️ Не удалось подтвердить отправку отклика
   Критерии: sequence=False, text=False, snapshot=False
```
**Причина:** Все три критерия провалились  
**Решение:** 
1. Проверьте что агент действительно отправил отклик
2. Посмотрите последние итерации Browser Agent
3. Проверьте `expected_status` - должен быть `"application_sent"`

#### Проблема: Вакансия в `processed_vacancies` без деталей
```json
{
  "title": "",
  "company": "",
  "url": "https://hh.ru/vacancy/123"
}
```
**Причина:** Парсинг не смог извлечь информацию  
**Решение:** Функция `_parse_vacancy_details()` работает best-effort, но URL всегда должен быть

### 6. Дебаг режим

Для более детальных логов установите уровень DEBUG:
```python
# В main.py
logging.basicConfig(
    level=logging.DEBUG,  # Было: logging.INFO
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
)
```

Вы увидите дополнительные логи:
```
DEBUG - 📸 Получен snapshot страницы (15234 символов)
DEBUG -    📝 Найдено название: ML Python developer...
DEBUG -    🔍 Найден клик на 'Откликнуться'
```
